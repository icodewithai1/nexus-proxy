✦ About

browser.lol proxy edition is a single-file proxy browser. Requests are handed to libcurl.js — a port of curl-impersonate to WebAssembly — which opens real TCP + TLS connections to destination sites and multiplexes them through a Wisp WebSocket relay. The relay never sees plaintext: TLS terminates inside your browser, and curl-impersonate's browser-like TLS fingerprint keeps requests natural.

Known limits

Pages render through a rewriter (this is a single file — no service worker). Sites that build their DOM heavily in JavaScript may look broken; toggle Safe mode for clean reading, and use the Session containers for logins. Large media streams are fetched fully before playback.
